# Organization

**Ontology:** `org:Organization`, `foaf:Organization`, `schema:Organization`
**Links to:** organization (sub-organisation of)

An institution, company, department, or other formal group of people.
Organisations can be nested using the `sub_organization_of` relation.

## What it defines

Custom properties: name, URL, city, ROR identifier.
Relation: sub-organisation of (another organisation).

# Person

**Ontology:** `foaf:Person`, `schema:Person`

A human individual. Base k-type for all person-like concepts in the DSMS.

## When to use

Use `person` when you need to record a human individual without implying any specific role or
expertise. In most cases you will want a more specific k-type:

| If the person is… | Use instead |
|---|---|
| A researcher, engineer, or technician | [expert](../expert/) |

## What it defines

Custom properties: first name, last name, email, ORCID.

# Changelog — Project

## [0.3.0] — 2026-06-03

### Added

- `context: true` — marks project instances as context anchors; k-items can be
  registered as members to scope graph views and queries to a specific project.

---

## [0.2.0] — 2026-05-11

### Added

- Custom properties: project homepage, start date, end date, grant / project ID,
  funding programme, call / programme URL.
- Relations: coordinator / PI (expert), participants (expert),
  partner organisations (organization), funder (organization), publications (document).

## [0.1.0] — 2026-05-10

- Initial skeleton: name, description, ontology classes (`vivo:Project`, `schema:ResearchProject`).

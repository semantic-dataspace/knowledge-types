# Changelog — Manufacturing Process

## [0.1.0] — 2026-04-28

- Initial specification.
- Extends `process`.
- Ontology class: `pmdco:ManufacturingProcess`.
- Semantic schema: `manufacturing/step/base/PMDCo` v2.0.0.
- Custom properties: duration, temperature.
- Relations: has_operator, has_input, has_output, has_dataset.

### Fixed

- Updated PMDCo IRI from human-readable `https://w3id.org/pmd/co/ManufacturingProcess` to
  verified numeric form `https://w3id.org/pmd/co/PMD_0000833`.

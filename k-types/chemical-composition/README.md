# Chemical Composition

**Ontology:** `pmdco:ChemicalComposition`
**Semantic schemas:** `chemical-composition/PMDCo` v1.0.0, `chemical-composition/BWMD` v1.0.0
**Links to:** material, specimen (composition of)

The elemental or molecular composition of a material. Each record describes the element
fractions for one material or specimen and produces RDF triples via the semantic schemas.

## Two schema variants

| Schema | Ontology | Use when |
|---|---|---|
| `chemical-composition/PMDCo` | PMDCo | Default; aligns with the Platform MaterialDigital core ontology |
| `chemical-composition/BWMD` | BWMD | Fraunhofer IWM projects using the BWMD ontology |
